ASC 2026 Data Portfolio

One clean handoff for the full race capture.

This page is meant to answer the teammate question fast: what was collected, how much of it exists, how trustworthy it looks, and where to open the raw files next. The Git repo now carries a portable archival dataset, daily coverage summaries, team metrics, and a restore path back to a working raw layout.

If you delete the local raw folderYou still keep the actual collected content. The tracked `dataset/raw` folder is the portable source of truth, and `restore_dataset.py` can rebuild a working raw layout from it.
Open these first`dataset/TEAMMATE_GUIDE.md`, `dataset/summary.json`, `dataset/daily_coverage.csv`, and `dataset/team_metrics.csv` are the quickest non-visual entry points for a teammate.
Biggest route in this capture#30 Delft covered about 3,631.2 km (2,256.3 mi) in the derived local route math.
